# Roadmap

## v0.1 — proposal and examples

- [x] Multi-goal vocabulary and task/attempt distinction.
- [x] Draft scheduling, ownership, recovery, and acceptance semantics.
- [x] Concrete multi-goal plan with static validation and tests.
- [x] Research bibliography and experiment methodology.

## Next — validate the design

- [ ] Gather real coordination failures and competing approaches through RFCs.
- [ ] Build a small reference executor with durable events and injected failures.
- [ ] Run equal-budget single-agent and multi-agent comparisons.
- [ ] Test cancellation, resource fencing, uncertain side effects, and starvation.
- [ ] Publish a versioned schema when runtime contracts stabilize.
- [ ] Map the contracts to existing runtimes and independent-agent protocols.

## Later — earned recommendations

- [ ] Publish reproducible results and revise practices based on evidence.
- [ ] Define interoperability tests if multiple implementations emerge.
- [ ] Establish broader maintainership and a documented decision process.

No delivery dates or production guarantees are implied.
